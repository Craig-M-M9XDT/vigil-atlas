# Vigil Atlas v0.3.1

Performance improvements and new intelligence dashboard panels.

### New features
- Live webcams: open and stop public, embeddable YouTube live feeds on demand.
- Local AI Insights: analyse GDELT conflict summaries using a configured local Ollama model.
- Stock-market watchlist: add and remove up to 15 symbols with locally saved selections.
- Stock analyst panel: available analyst targets and rating counts.
- Energy pricing: WTI crude, Brent crude and natural gas datasets.
- Regional weather: current conditions at the map centre through Open-Meteo.

### Improvements
- Fixes 1h/6h/24h server time-range parsing.
- Caches GDELT map aggregation and skips identical GeoJSON map refreshes.
- Aborts outdated fetch requests and loads time-dependent map layers concurrently.

### Setup and limitations
- Markets and energy data require a server-side Alpha Vantage API key (`AlphaVantage__ApiKey`); certain functions may require a paid subscription. Stock quotes may be delayed and energy data is dated as supplied by the provider.
- Local AI requires an installed Ollama service and model (default `llama3.2:3b`).
- Webcam streams are user supplied; live availability and embedding restrictions depend on the broadcaster.
- Open-Meteo free access has usage/licensing limitations. Respect external API terms.
- The Linux ARM64 build has not been validated on physical Raspberry Pi hardware.
- This release is self-contained; no separately installed .NET runtime is required.

### Install
Windows: extract `VigilAtlas-v0.3.1-win-x64.zip` and run `VigilAtlas.exe`.
Raspberry Pi (64-bit OS): extract `VigilAtlas-v0.3.1-linux-arm64.zip`, make `VigilAtlas` executable, and run it. For desktop app mode, install Chromium.
