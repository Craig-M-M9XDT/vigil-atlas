# Vigil Atlas v0.3 development features

This branch is **not a production release**.

## Local AI Insights

1. Install [Ollama](https://ollama.com/) on the machine running Vigil Atlas.
2. Run `ollama pull llama3.2:3b` and ensure the Ollama service is running.
3. Start Vigil Atlas and load the **conflicts** layer; click **Analyse top conflict events**.
4. To select a different model set `Ollama__Model`. To change the local endpoint set `Ollama__Url` (defaults to `http://127.0.0.1:11434`).

The endpoint processes at most 25 event summaries, with 300 characters per summary. It is **on-demand** and should only be exposed to trusted users. Local prompts and model replies may contain errors: validate reports against original feeds.

## Live webcams

Paste the URL of an authorised, embeddable public YouTube live feed and click **Open camera**. **Close / stop** removes the embedded player; it does not keep streaming in the background. Streams may become private, unavailable, or disallow embedding. The operator is responsible for stream rights.

## Performance changes

- Numeric time windows are parsed as 1, 6 or 24 hours rather than reverting to 6.
- GDELT aggregates cached for up to 20 seconds; invalidated when new events load or expire.
- Obsolete browser fetches are aborted, unchanged GeoJSON is not reapplied to MapLibre, and time-range fetches run concurrently.
- GitHub Actions validates compilation and publishes test binaries for Windows x64 and Linux ARM64.
