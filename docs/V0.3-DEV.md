# Vigil Atlas v0.3 development features

This branch is **not a production release**.

## Local AI Insights

1. Install [Ollama](https://ollama.com/) on the machine running Vigil Atlas.
2. Run `ollama pull llama3.2:3b` and ensure the Ollama service is running.
3. Start Vigil Atlas and load the **conflicts** layer; click **Analyse top conflict events**.
4. To select a different model set `Ollama__Model`. To change the local endpoint set `Ollama__Url` (defaults to `http://127.0.0.1:11434`).

The endpoint processes at most 25 event summaries, with 300 characters per summary. It is **on-demand** and should only be exposed to trusted users. Local prompts and model replies may contain errors: validate reports against original feeds.

## Live webcams

Paste the URL of an authorised, embeddable public YouTube live feed and click **Open camera**. **Close / stop** removes the embedded player; it does not keep streaming in the background. Streams may become private, unavailable, or disallow embedding. The operator is responsible for stream rights.

## Performance changes

- Numeric time windows are parsed as 1, 6 or 24 hours rather than reverting to 6.
- GDELT aggregates cached for up to 20 seconds; invalidated when new events load or expire.
- Obsolete browser fetches are aborted, unchanged GeoJSON is not reapplied to MapLibre, and time-range fetches run concurrently.
- GitHub Actions validates compilation and publishes test binaries for Windows x64 and Linux ARM64.

## Stocks, analyst metrics, oil, gas and weather

Configure an Alpha Vantage key on the Vigil Atlas server via `AlphaVantage__ApiKey` (do not put it in client JavaScript or commit it). Market requests run through the backend with a 15-minute quote cache, 24-hour fundamental/analyst cache and 2-hour commodity cache. The default watchlist contains AAPL and MSFT, supports up to 15 ticker symbols, and persists only in the current browser's localStorage. Alpha Vantage may limit call rates or restrict certain markets and commodity endpoints by subscription; when not available, the UI reports that rather than inventing prices. No brokerage connection or trade execution is provided.

The **Analyst** button shows Alpha Vantage company overview fields including target price and analyst rating counts where available. They are third-party aggregates, not original research, and do not represent investment advice. The quotation contains its latest trading date, while daily or monthly commodity series indicate their actual observation dates and units. **WTI and Brent crude are usually quoted in USD per barrel; US natural gas is commonly USD per million BTU; check the displayed source unit.**

The weather panel gets current reported/modelled conditions for the **map centre** from Open-Meteo. Pan to a region and click Refresh to see that region's conditions. The free non-commercial weather service may impose usage restrictions; check licence and subscription terms for commercial deployment. No automated market refresh is enabled to avoid exceeding free-tier limits.
